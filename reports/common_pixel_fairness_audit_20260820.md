# Common-Pixel Fairness Audit（Ω_common 共同像素重评）2026-08-20

日期：2026-08-20
前置：CTP-v1 冻结（`configs/ctp_v1_frozen.json`，SHA-256 `788f1962…`，commit `f54c034`）；Potsdam 冻结协议 `configs/potsdam_ctp_v1_protocol.json`；所有输入为冻结产物（scores / candidates / subsets / GT），无重新推断。

## 1. 动机与问题（Q1–Q4）

各方法在"是否给出有效预测"上行为不同（FusionCanvas 冲突忽略 255 / 未覆盖 255）。方法 A 可能在它"敢预测"的像素上占优，但通过忽略困难像素获得表面优势。共同像素审计把**所有方法都给出有效预测且 GT 有效**的像素集合 Ω_common 固定下来，在该集合上重算全部指标，回答：

- **Q1**：CTP vs C2 的 H-IoU 优势在完全相同像素上是否成立？
- **Q2**：CTP vs SCC 的优势在完全相同像素上是否成立？
- **Q3**：C2 > CTP 的差距在共同像素上是缩小、不变还是扩大？
- **Q4**：是否存在方法通过忽略更多困难像素获得表面优势（coverage 分析）？

## 2. 协议

- Ω_common(图像) = {p : GT(p) ≠ 255 ∧ ∀ method ∈ {Text, C2, SCC, CTP, Guard}, pred_m(p) ≠ 255}。
- 每个方法在同一 Ω_common 上重算 OA / Macro-F1 / mIoU / S/U/H-F1 / S/U/H-IoU（`src/ov_probe/final_audit.py::common_pixel_metrics`，一致性由 `tests/test_final_audit.py` 覆盖）。
- coverage_ratio = |Ω_common| / |方法自身有效像素|；原始指标与共同像素指标并列报告。
- 数据集：Vaihingen partial-support（k=2/3/4 × seed 42/43/44，9 subsets，5 test areas）与 Potsdam partial-support（ratio 25/50/75% × seed 42/43/44，9 subsets，14 parent tiles，3502 patches）。
- 注：Potsdam r25 三个子集实际支持类数 |S|=1（manifest 预注册），此时按冻结分数恒等式 SCC≡CTP≡Text（|S|=1 时 S_c^SCC = A_s−(A_s−T_s)=T_s），其对比只对 C2 有信息量；r50→k=2、r75→k=4。
- 全支持（k=C）时按冻结边界性质 CTP == SCC == C2（Unsupported=∅），共同像素审计无新增方法间差异，故只报告 partial-support（论文同口径）。

## 5. Q1–Q4 回答

- **Q1（CTP vs C2，共同像素）**：成立。Vaihingen 9/9、Potsdam 9/9 子集中 CTP H-IoU > 0（0.054–0.244）而 C2 = 0.000；聚类级 bootstrap 中 dH-IoU vs C2 在全部 18 个子集 CI 不含 0（sign=1.000）。C2 的 unsupported 崩溃是**方法本身**的行为，与像素选择无关。
- **Q2（CTP vs SCC，共同像素）**：成立（更强）。Vaihingen 8/9（k4_seed44 例外，SCC 0.306 > CTP 0.240）、Potsdam 9/9 子集 CTP H-IoU ≥ SCC；聚类 bootstrap：Vaih 6/9 sig+、Potsdam 非退化 6/6 sig+（r25 恒等）。CTP 的 margin 门控在相同像素上确实恢复了一部分被 SCC 全局偏移压掉的 unsupported 信号。
- **Q3（C2>CTP 的差距）**：**缩小或消失**。Vaihingen 中 C2 在 orig 像素领先 OA 的 4 个子集（k3_s42 +0.010、k4_s42 +0.044、k4_s43 +0.014、k4_s44 +0.055）在共同像素上全部缩小（−0.005、+0.014、−0.013、+0.026），其中两个转为 CTP 领先；CTP 在 orig 领先的 4/9 子集在共同像素上扩大为 5/9。Potsdam 非退化子集 CTP 在 OA 上赢/平 4/6（r50_s44、r75_s42/43/44），C2 领先的 r50_s42/s43 差距在共同像素上基本不变（+0.043→+0.033、+0.036→+0.039）。结论：**C2 的少量 OA 领先主要来自它多预测的像素（这些像素对 C2 相对容易），在共同像素上 C2 的优势显著收窄甚至反转**。
- **Q4（忽略像素的表面优势）**：**不存在**。coverage（|Ω_common|/自身有效像素）最低的是 C2（Vaih ≈0.62–0.68）与 Guard（≈0.61–0.67），即它们**预测了更多**像素而非更少；CTP 的 coverage 普遍高于 C2/Guard（如 Potsdam r50_s42：CTP 0.865 vs C2 0.800 vs Guard 0.817；r75_s44：0.879/0.883/0.862）。CTP 共同像素 OA ≥ 自身原始 OA 的子集占多数（Vaih 6/9、Potsdam 非退化 4/6），说明 CTP 排除的像素对它更困难，其指标没有被"忽略简单像素"注水。全支持证据一致：CTP 冲突忽略 44.4M px < C2 52.5M px（Potsdam full-support）。

## 6. 结论

共同像素审计确认：CTP 相对 C2/SCC 的优势是方法级的（与像素选择无关）；C2 的 OA 领先在共同像素上缩小或消失；没有任何方法通过忽略困难像素获得表面优势（C2/Guard 反而覆盖更多像素且共同像素质量不升）。Guard 在 U/H 上仍高于 CTP（见 `guard_pixel_baseline_20260820.md`），这与冻结期区域级结论一致。
