## 1. 定位声明（按用户协议）

本实验是 **Frozen CLIP semantic sanity check**，**不是 segmentation 结果**。协议 `voc2012_openai_clip_presence_eval_protocol_v1.json` 的 role 与 scope_disclosure 明确：

> "This is a fixed external image-level presence evaluation of an already-computed score cache. It is not a segmentation mIoU result and does not establish general scientific evidence by itself."

约束：`segmentation_miou=false`、`threshold_selection=false`、`prompt_selection=false`、`score_mutation=false`。任何后续 VOC visual anchor 工作只能称为 **oracle-region semantic recognition**，不得称为 VOC segmentation。

## 2. 流程（已完成，全部 CLIP inference 先于 GT 读取）

1. 完成全部 CLIP inference：`voc2012_openai_clip_zeroshot_v1/run_20260815_001`（1449 张 VOC 2012 Segmentation val 图像的冻结 OpenAI-CLIP 零样本 score cache：`scores_openai_clip.npy`、`image_ids.json`、`image_feature_stats.json`、`manifest.json`）
2. 之后才读取 segmentation mask：presence eval 只读 `SegmentationClass/<image_id>.png` 的类别 ID（背景 0 与 void 255 忽略），不访问 JPEGImages/Annotations/ImageSets/类特定文件
3. 转换为 image-level multi-label GT：类 c 存在 ⟺ 任一 mask 像素解码出 VOC 类 ID c
4. 计算 uninterpolated AP 与 macro mAP（相等分数合并为一个阈值；零正样本类 fail-closed）

## 4. 结论与定位

- macro mAP 0.727 表明冻结 OpenAI CLIP 在 VOC 图像级存在性排序上有合理语义灵敏度（作为 sanity check 成立），但 person/chair/car 等类 AP 显著偏低，与遥感场景结论一致：CLIP 的开放词表排序能力存在类别差异。
- **明确不作为 segmentation 证据**：本实验无像素级 mIoU、无阈值选择、无 prompt 调整，仅验证分数缓存的排序质量。
- 不根据 VOC 结果修改任何方法（无 prompt/threshold/方法调整）。
